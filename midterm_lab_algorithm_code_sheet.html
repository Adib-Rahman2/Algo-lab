1. Activity Selection

Greedy algorithmSort by finish timeO(n log n)

Goal: Select the maximum number of mutually compatible activities. Activity i has start time s[i] and finish time f[i]. The standard convention is that an activity can start exactly when the previous one finishes: next.start >= last.finish.

Core idea

  1. Sort activities in ascending order of finish time.
  2. Select the first activity (earliest finish).
  3. Scan the rest. Select an activity if its start time is at least the finish time of the last selected activity.
Why earliest finish? It leaves the largest remaining time window for future activities. This greedy choice is optimal for the unweighted problem.

Complete program — input as start/finish pairs

#include <bits/stdc++.h>
using namespace std;

struct Activity {
    int start, finish, id;
};

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    vector<Activity> a(n);
    for (int i = 0; i < n; i++) {
        cin >> a[i].start >> a[i].finish;
        a[i].id = i + 1;
    }

    sort(a.begin(), a.end(), [](const Activity& x, const Activity& y) {
        if (x.finish != y.finish) return x.finish < y.finish;
        if (x.start != y.start) return x.start < y.start;
        return x.id < y.id;
    });

    vector<Activity> selected;
    int lastFinish = INT_MIN;

    for (const auto& act : a) {
        if (act.start >= lastFinish) {
            selected.push_back(act);
            lastFinish = act.finish;
        }
    }

    cout << "Maximum activities: " << selected.size() << '\\n';
    cout << "Selected activity IDs: ";
    for (const auto& act : selected) cout << act.id << ' ';
    cout << '\\n';

    cout << "Selected intervals:\\n";
    for (const auto& act : selected)
        cout << act.start << " " << act.finish << '\\n';

    return 0;
}

Input format: first n, then n lines containing start finish. IDs in output refer to original input order.

Complexity: sorting O(n log n), scan O(n), total O(n log n). Extra space O(n) for stored and selected activities (excluding sorting implementation details).

Common mistakes

  • Sorting by start time instead of finish time.
  • Updating lastFinish even when an activity is rejected.
  • Using > instead of >= when back-to-back activities are allowed.
  • Assuming this solves maximum profit. It does not.
  • Forgetting to retain original indices when the question asks which input activities were selected.

2. Huffman Coding

Greedy algorithmMin-priority queuePrefix-free code

Goal: Construct an optimal prefix-free binary code for symbols with known frequencies. Repeatedly combine the two least-frequent nodes. The first removed node becomes the left child (bit 0), the second becomes the right child (bit 1).

Core steps

  1. Create one leaf node per symbol with its frequency.
  2. Insert all leaves into a min-priority queue.
  3. Remove the two minimum-frequency nodes.
  4. Create a parent with frequency equal to their sum; attach the two nodes as children.
  5. Insert the parent. Repeat until one root remains.
  6. Traverse the tree: left edge = 0, right edge = 1. The root-to-leaf path is the symbol's code.
Prefix-free property: No symbol's code is the prefix of another symbol's code. This allows unambiguous decoding without separators.

Complete program — build tree, print codes, encode and decode

#include <bits/stdc++.h>
using namespace std;

struct Node {
    char ch;
    long long freq;
    Node *left, *right;

    Node(char c, long long f) : ch(c), freq(f), left(nullptr), right(nullptr) {}
    Node(Node* l, Node* r)
        : ch('\\0'), freq(l->freq + r->freq), left(l), right(r) {}
    bool isLeaf() const {
        return left == nullptr && right == nullptr;
    }
};

struct Compare {
    bool operator()(const Node* a, const Node* b) const {
        if (a->freq != b->freq) return a->freq > b->freq;
        return a->ch > b->ch;
    }
};

void buildCodes(Node* root, string code,
                unordered_map<char,string>& codes) {
    if (!root) return;

    if (root->isLeaf()) {
        codes[root->ch] = code.empty() ? "0" : code;
        return;
    }

    buildCodes(root->left, code + "0", codes);
    buildCodes(root->right, code + "1", codes);
}

string encode(const string& text,
              const unordered_map<char,string>& codes) {
    string bits;
    for (char ch : text) {
        auto it = codes.find(ch);
        if (it == codes.end())
            throw runtime_error("Input contains a symbol absent from the Huffman tree");
        bits += it->second;
    }
    return bits;
}

string decode(const string& bits, Node* root) {
    if (!root) {
        if (bits.empty()) return "";
        throw runtime_error("Cannot decode with an empty tree");
    }

    if (root->isLeaf()) {
        for (char bit : bits)
            if (bit != '0') throw runtime_error("Invalid bit for single-symbol tree");
        return string(bits.size(), root->ch);
    }

    string result;
    Node* cur = root;

    for (char bit : bits) {
        if (bit == '0') cur = cur->left;
        else if (bit == '1') cur = cur->right;
        else throw runtime_error("Encoded input must contain only 0 and 1");

        if (!cur) throw runtime_error("Invalid encoded bit sequence");

        if (cur->isLeaf()) {
            result += cur->ch;
            cur = root;
        }
    }

    if (cur != root)
        throw runtime_error("Incomplete final codeword");

    return result;
}

void deleteTree(Node* root) {
    if (!root) return;
    deleteTree(root->left);
    deleteTree(root->right);
    delete root;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n;
    cin >> n;

    if (n < 0) {
        cout << "Invalid number of symbols\\n";
        return 0;
    }

    priority_queue<Node*, vector<Node*>, Compare> pq;
    unordered_set<char> seen;

    for (int i = 0; i < n; i++) {
        char ch;
        long long freq;
        cin >> ch >> freq;

        if (freq < 0 || seen.count(ch)) {
            cout << "Invalid frequency or duplicate symbol\\n";
            while (!pq.empty()) {
                deleteTree(pq.top());
                pq.pop();
            }
            return 0;
        }

        seen.insert(ch);
        pq.push(new Node(ch, freq));
    }

    if (pq.empty()) {
        cout << "No symbols provided\\n";
        return 0;
    }

    while (pq.size() > 1) {
        Node* left = pq.top(); pq.pop();
        Node* right = pq.top(); pq.pop();
        pq.push(new Node(left, right));
    }

    Node* root = pq.top();

    unordered_map<char,string> codes;
    buildCodes(root, "", codes);

    cout << "Huffman Codes:\\n";
    vector<pair<char,string>> ordered(codes.begin(), codes.end());
    sort(ordered.begin(), ordered.end());
    for (auto& [ch, code] : ordered)
        cout << ch << " : " << code << '\\n';

    string message;
    cout << "Enter message to encode (one token): ";
    cin >> message;

    try {
        string bits = encode(message, codes);
        cout << "Encoded: " << bits << '\\n';
        cout << "Decoded: " << decode(bits, root) << '\\n';
    } catch (const exception& e) {
        cout << e.what() << '\\n';
    }

    deleteTree(root);
    return 0;
}

Input format: number of symbols, then one character and its frequency per line, then a one-token message to encode. This compact input format assumes symbols do not contain whitespace.

Variation A — only print Huffman codes

If the question only asks for codes, you need the node structure, min-priority queue, and recursive traversal. Omit encode, decode, and the message input.

void printCodes(Node* root, string code = "") {
    if (!root) return;

    if (!root->left && !root->right) {
        cout << root->ch << " : "
             << (code.empty() ? "0" : code) << '\\n';
        return;
    }

    printCodes(root->left, code + "0");
    printCodes(root->right, code + "1");
}

Variation B — frequencies from a text string

string text;

for (char ch : text) freq[ch]++;

    cout << ch << " " << count << '\\n';

Variation C — calculate total encoded cost

Total weighted path length is the sum of frequency × code length. You can calculate it from the generated code map:

long long totalBits = 0;
for (auto [ch, code] : codes)
    totalBits += frequency[ch] * (long long)code.size();

cout << "Total bits: " << totalBits << '\\n';

2 symbolsBoth are direct children; codes are 0 and 1.

The exact codes depend on tie-breaking and left/right assignment. Verify prefix-freeness and total weighted code length rather than memorizing one output.

Complexity

  • Tree construction: O(k log k), where k is the number of distinct symbols.
  • Generating codes: O(k) tree traversal, excluding the total number of output bits in the strings.
  • Encoding: O(L) plus output size, where L is message length.
  • Decoding: O(B), where B is encoded bit length.
  • Tree space: O(k). Code storage is proportional to the total code lengths.

Common mistakes

  • Using a max-heap instead of a min-heap.
  • Combining the two largest frequencies instead of the two smallest.
  • Forgetting to push the new parent back into the queue.
  • Printing internal nodes as symbols. Only leaves represent symbols.
  • Forgetting the single-symbol case, which otherwise produces an empty code.
  • Assuming exact bit strings are unique when frequencies tie.
  • Using int for frequency sums when constraints may require long long.

3. Longest Common Subsequence (LCS)

Dynamic programming2D tableO(mn)

Goal: Find the longest sequence that appears in both strings in the same relative order. Characters do not need to be contiguous. For example, the LCS of ABCBDAB and BDCABA has length 4; one valid LCS is BCBA (another valid answer may exist).

Subsequence is not substring. A substring must be contiguous. An LCS may skip characters in either input.

Recurrence

Let dp[i][j] be the LCS length of the first i characters of string A and first j characters of string B.

  • Base: dp[0][j] = dp[i][0] = 0.
  • If A[i-1] == B[j-1]: dp[i][j] = 1 + dp[i-1][j-1].
  • Otherwise: dp[i][j] = max(dp[i-1][j], dp[i][j-1]).

Complete program — LCS length, one actual LCS, and DP table

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string a, b;
    getline(cin, a);
    getline(cin, b);

    int m = (int)a.size();
    int n = (int)b.size();

    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (a[i - 1] == b[j - 1])
                dp[i][j] = 1 + dp[i - 1][j - 1];
            else
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }

    int lcsLength = dp[m][n];
    string lcs;
    int i = m, j = n;

    while (i > 0 && j > 0) {
        if (a[i - 1] == b[j - 1]) {
            lcs.push_back(a[i - 1]);
            i--;
            j--;
        } else if (dp[i - 1][j] >= dp[i][j - 1]) {
            i--;
        } else {
            j--;
        }
    }

    reverse(lcs.begin(), lcs.end());

    cout << "LCS length: " << lcsLength << '\\n';
    cout << "One LCS: " << lcs << '\\n';

    cout << "DP Table:\\n";
    for (const auto& row : dp) {
        for (int value : row) cout << value << ' ';
        cout << '\\n';
    }

    return 0;
}

Input format: two complete lines, one string per line. getline preserves spaces and also permits an empty string line.

Variation A — only calculate LCS length

int lcsLength(string a, string b) {
    int m = a.size(), n = b.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (a[i - 1] == b[j - 1])
                dp[i][j] = dp[i - 1][j - 1] + 1;
            else
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
        }
    }
    return dp[m][n];
}

Variation B — reconstruct one LCS

Start at dp[m][n]. If the current characters match, include the character and move diagonally. Otherwise move toward the neighboring cell with the larger DP value. Reverse the collected characters at the end.

string getLCS(string a, string b) {
    int m = a.size(), n = b.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= m; i++)
        for (int j = 1; j <= n; j++)
            dp[i][j] = (a[i - 1] == b[j - 1])
                ? dp[i - 1][j - 1] + 1
                : max(dp[i - 1][j], dp[i][j - 1]);

    string ans;
    int i = m, j = n;
    while (i > 0 && j > 0) {
        if (a[i - 1] == b[j - 1]) {
            ans += a[i - 1];
            i--; j--;
        } else if (dp[i - 1][j] >= dp[i][j - 1]) {
            i--;
        } else {
            j--;
        }
    }
    reverse(ans.begin(), ans.end());
    return ans;
}

Variation C — space-optimized length only

Use this only when the question asks for the length, not to print the sequence or reconstruct it. It reduces DP storage from O(mn) to O(min(m,n)).

int lcsLengthOptimized(string a, string b) {
    if (b.size() > a.size()) swap(a, b);

    int m = a.size(), n = b.size();
    vector<int> prev(n + 1, 0), cur(n + 1, 0);

    for (int i = 1; i <= m; i++) {
        fill(cur.begin(), cur.end(), 0);
        for (int j = 1; j <= n; j++) {
            if (a[i - 1] == b[j - 1])
                cur[j] = prev[j - 1] + 1;
            else
                cur[j] = max(prev[j], cur[j - 1]);
        }
        swap(prev, cur);
    }
    return prev[n];
}

Variation D — print all distinct LCS strings (advanced)

Some questions ask for all distinct LCS strings. This can produce exponentially many outputs, so it is not the usual basic lab requirement. The memoized set-based approach below is suitable only for small strings.

set<string> allLCS(
    int i, int j,
    const string& a, const string& b,
    const vector<vector<int>>& dp,
    map<pair<int,int>, set<string>>& memo
) {
    if (i == 0 || j == 0) return {""};

    auto key = make_pair(i, j);
    if (memo.count(key)) return memo[key];

    set<string> result;

    if (a[i - 1] == b[j - 1]) {
        for (const string& s : allLCS(i - 1, j - 1, a, b, dp, memo))
            result.insert(s + a[i - 1]);
    } else {
        if (dp[i - 1][j] >= dp[i][j - 1]) {
            auto top = allLCS(i - 1, j, a, b, dp, memo);
            for (auto& s : top)
                if ((int)s.size() == dp[i][j]) result.insert(s);
        }
        if (dp[i][j - 1] >= dp[i - 1][j]) {
            auto left = allLCS(i, j - 1, a, b, dp, memo);
            for (auto& s : left)
                if ((int)s.size() == dp[i][j]) result.insert(s);
        }
    }

    return memo[key] = result;
}

First build the standard DP table. Then call allLCS(m, n, a, b, dp, memo) and print the returned set. The number of distinct answers can be very large.

Example and DP intuition

Input:
ABCBDAB
BDCABA

Output:
LCS length: 4
One LCS: BCBA

At each cell, a matching pair extends the diagonal solution. A mismatch means the best solution must skip one character from A or one from B, so take the larger of the top and left cells.

Common mistakes

  • Using a[i] and b[j] instead of a[i-1] and b[j-1] in a 1-based DP table.
  • Allocating only m × n instead of (m+1) × (n+1).
  • Forgetting to initialize the first row and first column to zero.
  • When reconstructing, forgetting to reverse the collected string.
  • Printing only the length when the question asks for the actual subsequence.
  • Claiming the LCS is unique when several answers may exist.
  • Confusing subsequence with substring.
